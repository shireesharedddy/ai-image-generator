# AI Image Generator 

An AI-powered Image Generator built with **React (frontend)** and **Node.js + Express (backend)** using Unsplash API.

## Features
- Enter a text prompt and generate AI images instantly
- React frontend + Express backend integration
- Search Search for images using keywords
- Dynamic keyword-based search
- Fetch results from Unsplash API
- Responsive design
- Node.js backend to handle API calls securely

## Tech Stack
- Frontend: React, JavaScript, CSS
- Backend: Node.js, Express
- API: Unsplash API (or any image generation API)

## Frontend : 
 To Run React: npm start
 
 Runs on http://localhost:3000
- React app provides the UI for the Image Generator.


## Backend :
To Run Node.js: node server.js

Runs on http://localhost:5000
- Handles API requests and communicates with Unsplash API.

## Running the Full App

Start backend first (port 5000).

Start frontend next (port 3000).

Now frontend will fetch images via backend using Unsplash API.

## Environment Setup (API Key)

1. Create a `.env` file inside your **backend** folder.
2. Add your Unsplash API key:
3. Never share this key publicly (do not push `.env` file to GitHub).

The backend will automatically use this API key to fetch images securely.
